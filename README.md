# IRIS VS Code: QuickStart Sample

A minimal ObjectScript project used by the Instruqt **VS Code: QuickStart for InterSystems IRIS** lab.

## Files

- `src/VSCodeQuickstart/Greeter.cls` — a simple class with methods to edit, compile, run, and debug.

## What you will do

1. Install the InterSystems ObjectScript Extension Pack in VS Code:.
2. Clone this repository.
3. Open the project folder in VS Code:.
4. Configure `objectscript.conn` in `.vscode/settings.json`.
5. Edit `Greeter.cls` and compile it.
6. Run a method from the editor.
7. Set a breakpoint and debug the code.
8. Commit your changes with Git.
